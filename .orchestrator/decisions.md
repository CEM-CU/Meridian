[2026-03-29] DECISION: A4 pipeline stream uses _tagged() coroutine wrapper pattern for asyncio.as_completed identity tracking. When submitting N coroutines to as_completed, wrap each as `_tagged(key, coro)` so the awaited result is `(key, result)` rather than just `result`. This avoids task dict identity comparison problems with Python 3.14's asyncio. RATIONALE: `asyncio.as_completed` returns futures in completion order but does not preserve task identity — the standard dict[task→metadata] lookup pattern breaks under Python 3.14+. The _tagged() wrapper is a clean zero-overhead solution. FILES CHANGED: api/sse/pipeline_stream.py. DOWNSTREAM IMPACT: Any future parallel streaming patterns in the API layer should use _tagged().
